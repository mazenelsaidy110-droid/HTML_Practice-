# HTML Practice Collection

A collection of small HTML pages and exercises created while learning and practicing HTML.

## Goal

Practice building web pages with HTML, understand how page content is structured, and become more comfortable writing HTML independently.

## Built with

* HTML5

## How to view the pages

1. Clone or download this repository.
2. Open the project folder.
3. Open any `.html` file in your web browser.

You can also open the folder in Visual Studio Code and use a local preview extension while practicing.

## Learning focus

* HTML document structure
* Headings, paragraphs, links, and images
* Organizing content into page sections
* Practicing semantic HTML elements
* Building different types of simple web pages
